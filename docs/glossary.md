# Glossary

| Term | Plain meaning |
|---|---|
| Aggregation rule | A registered way to move a construct up a level, such as a team mean of individual scores. |
| Claim | A typed statement linking two constructs, with a direction, a scope, an evidence kind and a citation. The code calls this a proposition. |
| Compiler | The program checking every definition and claim. Lemma runs the checks inside Lean. |
| Composition | Chaining two claims to imply a third. |
| Construct | A named concept written as a set of parts at one level with one horizon. |
| Curated entry | A definition or claim the author wrote from the cited source. |
| Declaration | A recorded decision on an overlap, with a reason. |
| Evidence kind | The design behind a claim, such as meta-analytic, longitudinal, cross-sectional, or none. |
| Fixture | A hand-written file standing in for model output, so the pipeline can run with no model. |
| Horizon | The time span a construct covers, such as daily, weekly, or static. |
| Kernel | The small set of construction rules everything reduces to. The kernel holds zero psychological content. |
| Lean | A proof assistant from mathematics, used here as the checking engine. Reading results requires zero knowledge of Lean. |
| Level | The unit of analysis, such as individual, team, or organization. |
| Module | One file holding one theory. |
| Part | A basic quantity such as energy or attention. The code calls this a primitive. |
| Pipeline | The software route from a paper to a draft module to the compiler. |
| Precision | The share of machine-drafted entries a human reviewer judges faithful to the source. Precision remains unmeasured in this release. |
| Reduction | The check confirming a construct unfolds entirely into registered parts. |
| Scope | A level paired with a horizon, such as Individual / Weekly. |
| Temporal rule | A registered way to move a construct to a longer horizon. |
