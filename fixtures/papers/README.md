# Pilot papers

Each `.txt` file is a short structured summary, written for this
repository, of one source paper: title, reference, definitions of the
central constructs, and the propositions the paper states. The files are
not the papers' text. They stand in for the paper input of
`lemma formalize` so that the pipeline can be exercised without
redistributing copyrighted PDFs.

The matching hand-written formalizations are in `../formalizations/`.
